# TLI Sand Tracker – Downloads

Download the latest version from **[Releases](../../releases/latest)**.

- `TLI-Sand-Tracker-<version>-x64.exe` – portable, just start it.
- `TLI-Sand-Tracker-<version>-x64.zip` – unpack anywhere and start `TLI Sand Tracker.exe`.

The app checks this page on start and offers to update itself automatically (App > Check for updates…).
This repository only contains release builds.
